# Python dependencies for the data pipeline (src/00_pipeline.py) and for
# running/debugging it interactively in Cursor via its built-in Jupyter
# kernel (ipykernel). The website itself has no Python runtime - it is
# static files served from web/.
#
# Only direct dependencies are pinned; transitive dependencies are left to
# pip's resolver, since this file is installed on both the dev machine
# (x86_64, via the Docker dev container) and the Raspberry Pi (arm64, for
# the scheduled pipeline run) and pinning the full transitive graph would
# fight the resolver on one platform or the other.
#
# geopandas (+ pyproj, shapely, Fiona) is deliberately NOT listed here:
# Fiona has no Linux ARM64 wheel on PyPI at any version, which breaks this
# file's install on the Pi. It's only needed by
# src/03_geojson_processing.py, which is Windows-only - install it
# separately there (`pip install geopandas pyproj shapely Fiona`) when you
# need to run that script. global.py's `import geopandas` is wrapped in a
# try/except so every other step runs fine without it.
